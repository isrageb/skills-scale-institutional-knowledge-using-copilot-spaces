# OctoAcme Project Management Docs

This folder contains OctoAcme's shared guidance for planning and delivering cross-functional projects.

## Project management processes overview

OctoAcme uses an iterative, customer-focused project lifecycle: initiate and validate an idea, plan scope and delivery, execute and track work, release and verify changes, and close with a retrospective. Projects begin with a clear problem statement and measurable outcomes, then move through prioritized backlogs, defined acceptance criteria, small deliverable increments, and regular review.

Project Managers coordinate schedules, risks, dependencies, and communication. Product Managers define outcomes, prioritize work, and measure success. Developers and QA collaborate on implementation and testing, with stakeholders providing alignment and approvals. The team uses regular delivery rhythms, project boards, risk registers, CI-based quality checks, release plans, and documented escalation paths to maintain transparency and respond to blockers.
